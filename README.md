# Re-Shoot or Upscale? The Break-Even Point, Measured in Decibels and Millimetres

Measured on a real 1080x1620 capture: a 4x upscale scores 27.2 dB against the original but 32.5 dB once both are filtered to what the eye resolves. Ten experiments, three negative results.

**Read it with the tables and the reproduction snippets:** <https://celticgemini001.github.io/upgolab-upscale-vs-reshoot/>

## About this repo

This repository exists to serve one measured article. Every number in it came from
ffmpeg and numpy run on real files on this machine — the commands are in the page so
you can re-run them and get the same rows. Where the measurement contradicted the
hypothesis, the page says so.
